One ledger for

agent ever spends.

Most agent stacks solve "what goes in the window" and "what earns the call" as two separate, uncoordinated projects. Context Ledger is one runtime for both: a scored context toolkit that decides what's worth sending, and a deterministic Guardian that decides what's worth paying for — before either one reaches a provider.

Unifies two MIT-licensed projects by the same author — Tools-Tokens (context) and agent-finops-ZWCA (governance) — under one package, one test suite, one design system.

02

Context layer, in one call

from context_ledger.context import Headroom, index_path, pack_query headroom = Headroom(window=200_000, reserve_output=8_000) headroom.spend("conversation", 120_000) index = index_path("./src") context = pack_query("where is the retry backoff configured?", index, budget=6_000, headroom=headroom) print(context.text) # cited, budget-respecting context print(context.manifest()) # and the full account of how it got there

05

Limits — read before you adopt

×

Not yet wired end-to-end. The governance layer's Plane 2 (Context) still needs to be pointed at context_ledger.context's pack/headroom primitives instead of its own placeholder — that's the first integration milestone, tracked in docs/EXTENDING.md.

×

Targets, not production claims. The 85–90% blended reduction figures were calibrated against the original ZWCA pilot — re-run your own Phase 0 baseline.

×

No unlimited retries or automatic frontier escalation. A blocked call stays blocked.
